# Teman-Belajar
1. Judul dan masalah

Banyak para pelajar yang merasa kesulitan akan menata jadwal pembelajar mereka dirumah dan terkadang hanya membuat jadwal belajar mereka berantakan, efeknya sering kali dari mereka yang berakhir tidak mengerjakan tugas mereka. Daripada itu kami menciptakan Teman Belajar. 

Teman Belajar adalah website yang dirancang untuk membantu para pelajar menata jadwal pembelajaran, tugas, dan sekaligus membantu mereka belajar dari rumah dengan menghadirkan fitur Flash Card.

2. Tumpukan Teknologi

Website ini Berbasis HTML yang berfokus untuk mendesain dan membuat struktur halaman website.

3. Tautan Publik

https://munasukafiksi.github.io/Teman-Belajar/

4. Transparasi Ai

2 formula terbaik yang digunakan:

 1."kamu sedang mencoba membuat website berbasis HTML dan menggunakan website github.com untuk mempublikasi fan mencoba web mu.

 2. "Berikan kode lengkap tanpa di potong dalam satu blok kode, lalu jelaskan singkat cara menjalankannya."

Full prompt : 

kamu adalah seorang programer yang ahli dan sabar. kamu sedang mencoba membuat website berbasis HTML dan menggunakan website github.com untuk mempublikasi dan mencoba web mu. Website ini bernama "Teman belajar" dan digunakan untuk siswa siswa sekolah untuk membantu belajar(mengatur waktu, menata tugas, review materi dan pengingat)

Fitur yang aku mau :
1. To-do list yang bisa di beri catatan dan dapat di kelompokan sesuai ke inginan
2. Timer pomodoro yang dapat di atur durasi nya
3. Kalender yang dapat di beri catatan dan pengingat tugas yang akan di lakukan
4. Flash card yang bisa di mainkan sebagai mini game dengan materi yang bisa disesuaikan 

Gaya : minimalis, latar warna gelap dengan kombinasi warna pastel sebagai simbol/tombol lain, font arial bold sebagai judul dan arial normal sebagai penjelas, terlihat rapi dan profesional di hp maupun laptop.

Berikan kode lengkap tanpa dipotong dalam satu blok kode, lalu jelaskan singkat cara menjalankannya.


5. Rintangan dan Solusi :

Namun ketika di coba di github tidak berhasil maka dari itu kami mencoba lagi dengan rincian fitur, penampilan dan kode yang membuat website berhasil di buat.
